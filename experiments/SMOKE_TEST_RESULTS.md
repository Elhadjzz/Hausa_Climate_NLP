# NLLB + HESTC Smoke-Test Results

## Purpose

This smoke test verified the complete experimental path:

1. reconstruct the 11,034-record HESTC master corpus;
2. build the deterministic silver benchmark;
3. select held-out terminology;
4. download and run `facebook/nllb-200-distilled-600M`;
5. translate English→Hausa with unconstrained NLLB;
6. translate the same items with HESTC lexical constraints;
7. calculate terminology and constraint metrics;
8. upload reproducible result artifacts.

Successful GitHub Actions run:

https://github.com/Elhadjzz/Hausa_Climate_NLP/actions/runs/40947463757

## Scope

This was deliberately a **3-term engineering smoke test**, not a research-performance benchmark.

All three terms were from the Biodiversity, Ecology & Conservation domain and used the `Direct equivalence` candidate strategy.

## Silver terminology metrics

| System | Exact HESTC-candidate match | Constraint success |
|---|---:|---:|
| NLLB baseline | 0/3 (0%) | Not applicable |
| NLLB + HESTC constrained | 3/3 (100%) | 3/3 (100%) |

These numbers demonstrate **lexical controllability**, not translation superiority.

No BLEU or chrF score was calculated because no independently reviewed Hausa sentence references were present.

## Qualitative examples

### Pesticide risk to biodiversity

- English: **pesticide risk to biodiversity**
- provisional HESTC candidate: **maganin kashe ƙwari haɗari zuwa bambancin halittu**
- NLLB baseline: **hadarin kashe kwayoyin cutar ga halittu masu yawa**
- constrained output: **hadarin maganin kashe ƙwari haɗari zuwa bambancin halittu**

The constraint was successfully inserted, but the output does not establish that the provisional HESTC candidate is the best Hausa terminology.

### Ecosystem variable

- English: **ecosystem variable**
- provisional HESTC candidate: **tsarin halittu canji**
- NLLB baseline: **Canjin tsarin halittu**
- constrained output: **Tsarin tsarin halittu canji**

This example is particularly important. The baseline form appears to use a more natural Hausa word order, while forced inclusion reproduces the provisional candidate. This shows why candidate exact-match accuracy must not be interpreted as linguistic quality.

### Restoration potential

- English: **restoration potential**
- provisional HESTC candidate: **maido da muhalli yiwuwar**
- NLLB baseline: **iyawar sake dawowa**
- constrained output: **iyawar maido da muhalli yiwuwar sake dawowa**

Again, lexical forcing works technically, but human review is required to determine the scientifically accurate and natural preferred Hausa form.

## Methodological conclusion

The experiment validates the **engineering mechanism**: HESTC terminology can be detected and constrained during NLLB decoding.

It does **not** validate the provisional Hausa terminology.

Therefore the project should not scale directly from this smoke test to claims such as “HESTC improves Hausa translation by 100%.” The observed 100% figure only means that constrained decoding successfully inserted the requested provisional terminology in this tiny sample.

## Next research stage

Before publication-grade MT evaluation:

1. run the 200-term stratified human validation pilot;
2. correct provisional Hausa terminology;
3. promote only independently reviewed forms to `Validated`;
4. construct 500–1,000 independently translated climate sentences;
5. evaluate baseline NLLB versus HESTC-grounded NLLB using:
   - terminology accuracy;
   - constraint success;
   - chrF;
   - BLEU;
   - qualitative human adequacy/fluency review.

The validation pilot is generated by:

~~~bash
python src/merge_corpus_parts.py
python src/build_validation_pilot.py \
  --corpus data/HESTC10K_master.csv \
  --out data/validation/hestc_validation_pilot_200.csv
~~~
