# HESTC Hausa Terminology Validation Protocol

## Purpose

The current HESTC release contains provisional Hausa candidates. Human review is required before the resource should be described as a validated bilingual environmental terminology corpus.

## Reviewer roles

### Hausa linguist or terminologist

Reviews:

- natural Hausa usage;
- orthography;
- morphology;
- grammar;
- semantic transparency;
- ambiguity;
- intelligibility; and
- appropriateness of borrowing or transliteration.

### Environmental domain expert

Reviews:

- scientific equivalence;
- technical precision;
- consistency with the English definition;
- consistency with the institutional source; and
- suitability for scientific, policy or professional communication.

### Harmonization reviewer

Reviews:

- consistency across terminology families;
- recurring concepts across domains;
- acronym treatment;
- competing Hausa forms; and
- cross-domain consistency.

## Recommended priority order

1. `Needs expert coinage`
2. `Borrowing/transliteration`
3. Hybrid translation
4. Descriptive translation
5. Direct equivalence
6. Existing Hausa technical term

## Suggested reviewer decisions

- Accept
- Accept with minor revision
- Major revision
- Reject/replace
- Needs additional linguistic consultation
- Needs additional domain consultation

## Validation-status progression

```text
Candidate drafted
→ Under linguistic review
→ Under domain review
→ Validated
```

If the candidate is unsuitable:

```text
Candidate drafted
→ Rejected/revise
```

## Minimum validation record

For every term promoted to `Validated`, record:

- final preferred Hausa form;
- reviewer decision;
- reviewer note or rationale;
- date/version;
- linguistic reviewer role or identifier; and
- domain reviewer role or identifier.

## Scientific safety

For high-stakes climate, disaster, water, chemical, agricultural or public-health communication, a term should not be deployed as authoritative solely because it is present in the candidate corpus. Application developers should check validation status and retain source traceability.
